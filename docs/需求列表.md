## TR2 — SRAM 虚拟 U 盘

**目标**：读写命令打通 + 写路径验证，存储介质为 SRAM（断电丢失）。

> **2026-08-02 修订**：实测 Windows 无法格式化 ≤16KB 的 FAT 卷（`format` 报"卷对 FAT16/12 来说太大"，最小 FAT12 卷 ≥32KB），而 SRAM 仅 20KB → "被 Windows 格式化 + 文件读写"顺延至 TR3（W25Q32 Flash 4MB，满足最小卷要求）。TR2 以读写命令走通 + 写路径验证收尾。

### 开发任务（按提交顺序）

| 编号 | 状态 | 需求 | 涉及组件 |
|---|---|---|---|
| TR2-A1 | [ ] | mass_mal SRAM 介质层（8KB 数组 + Init/Read/Write/GetStatus） | mal |
| TR2-A2 | [ ] | scsi_data SCSI 静态响应数据（Inquiry/SenseData/ModeSense/ReadCapacity） | scsi_data |
| TR2-A3 | [ ] | usb_bot BOT 状态机骨架 + usb_endp 端点回调接管（CBW 解码 + CSW 返回，SCSI 全 INVALID） | bot, endp |
| TR2-A4 | [ ] | memory 缓冲调度骨架（Read_Memory/Write_Memory 框架） | buffer |
| TR2-B1 | [ ] | usb_scsi SCSI 查询命令 + bot CBW_Decode 接入，Problem Code 10 消失，PC 见 8KB 磁盘 | scsi, bot |
| TR2-C1 | [ ] | SCSI READ10 + memory Read_Memory 实现，可读取磁盘内容 | buffer, scsi |
| TR2-C2 | [ ] | SCSI WRITE10 + memory Write_Memory 实现，写路径验证（WinHex 写扇区读回一致；格式化顺延 TR3） | buffer, scsi |
| TR2-C3 | [ ] | 其余 SCSI 命令补全（VERIFY10/FORMAT_UNIT）+ 安全弹出验证 | scsi |

### 验收清单（最终状态检查）

| 编号 | 状态 | 需求 | 验收标准 | 对应开发任务 |

## TR3 — W25Q32 真实 U 盘

**目标**：完整 4MB U 盘，断电数据保持。承接 TR2 顺延的"格式化 + 文件读写"验收（SRAM 20KB 无法被 Windows 格式化，Flash 4MB 满足最小 FAT 卷要求）。

| 编号 | 状态 | 需求 | 验收标准 |
|---|---|---|---|
| TR3-01 | [ ] | W25Q32 正确识别 | 驱动初始化时能读取并验证 JEDEC ID (0xEF4016) |
| TR3-02 | [ ] | 设备上报 4MB 容量 | PC 显示 ~4MB（8192 扇区 × 512B） |
| TR3-03 | [ ] | 格式化正常 | 格式化为 FAT/FAT32 成功，容量显示正确 |
| TR3-04 | [ ] | 文件读写正常 | 创建/读取/修改/删除文件均正常 |
| TR3-05 | [ ] | 大文件写入正常 | 写入接近 4MB 的大文件，读取比对一致 |
| TR3-06 | [ ] | 断电数据保持 | 拔掉 USB 后重新插入，之前写入的文件仍存在且内容不变 |
| TR3-07 | [ ] | 重复插拔稳定 | 连续 10 次插拔 USB，每次均能正常识别和读写 |
| TR3-08 | [ ] | 异常处理 | Flash 初始化失败（如 JEDEC ID 不匹配）时设备不上报为就绪 |
