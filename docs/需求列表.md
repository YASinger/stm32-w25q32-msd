## TR1 — USB 枚举通过

**目标**：PC 能识别到 USB 大容量存储设备，并完整走通枚举流程。

### 开发任务（按提交顺序）

| 编号 | 状态 | 需求 | 涉及组件 |
|---|---|---|---|
| TR1-A1 | [x] | 工程骨架 + 库集成，main.c 空壳可编译 | Library, Start |
| TR1-A2 | [ ] | hw_config 硬件初始化（时钟/GPIO/NVIC/USB 时钟） | hwinit |
| TR1-A3 | [ ] | usb_conf.h 端点/PMA 地址/回调全指向 NOP_Process | endpoint |
| TR1-A4 | [ ] | usb_istr USB 中断入口 + ISTR 事件分发 | isr |
| TR1-B1 | [ ] | usb_desc 最小设备描述符（18B，VID/PID 合法） | desc |
| TR1-B2 | [ ] | usb_prop 设备属性表 + MASS_Reset + GetDeviceDescriptor | device |
| TR1-B3 | [ ] | usb_pwr PowerOn + bDeviceState 状态机 + fSuspendEnabled=FALSE | power |
| TR1-B4 | [ ] | main 主流程串联，设备出现在设备管理器 | main |
| TR1-C1 | [ ] | 配置描述符（MSC/Bulk-Only/2 Endpoint/自供电） | desc |
| TR1-C2 | [ ] | 字符串描述符（厂商/产品/序列号读 UID） | desc |

## TR2 — SRAM 虚拟 U 盘

**目标**：PC 可格式化并读写文件，存储介质为 SRAM（断电丢失）。

| 编号 | 状态 | 需求 | 验收标准 |
|---|---|---|---|
| TR2-S1 | [ ] | BOT 状态机与端点接管 | EP1/EP2 由 NOP 替换为真实 BOT 状态机，能接收 CBW、返回 CSW，设备无感叹号 |
| TR2-S2 | [ ] | SCSI 查询命令与 SRAM 介质层 | INQUIRY/READ_CAPACITY 等查询命令正确响应，PC 显示约 8KB 可移动磁盘，可格式化 |
| TR2-S3 | [ ] | SCSI 读写命令与文件操作 | READ10/WRITE10 走通，文件写入/读取/删除正确，大数据读写无错误 |
| TR2-S4 | [ ] | 安全弹出与断电验证 | 安全弹出无错误提示，拔掉 USB 重新插入需重新格式化 |

## TR3 — W25Q32 真实 U 盘

**目标**：完整 4MB U 盘，断电数据保持。

| 编号 | 状态 | 需求 | 验收标准 |
|---|---|---|---|
| TR3-01 | [ ] | W25Q32 正确识别 | 驱动初始化时能读取并验证 JEDEC ID (0xEF4016) |
| TR3-02 | [ ] | 设备上报 4MB 容量 | PC 显示 ~4MB（8192 扇区 × 512B） |
| TR3-03 | [ ] | 格式化正常 | 格式化为 FAT/FAT32 成功，容量显示正确 |
| TR3-04 | [ ] | 文件读写正常 | 创建/读取/修改/删除文件均正常 |
| TR3-05 | [ ] | 大文件写入正常 | 写入接近 4MB 的大文件，读取比对一致 |
| TR3-06 | [ ] | 断电数据保持 | 拔掉 USB 后重新插入，之前写入的文件仍存在且内容不变 |
| TR3-07 | [ ] | 重复插拔稳定 | 连续 10 次插拔 USB，每次均能正常识别和读写 |
| TR3-08 | [ ] | 异常处理 | Flash 初始化失败（如 JEDEC ID 不匹配）时设备不上报为就绪 |
