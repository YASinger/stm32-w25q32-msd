## 1. 需求分解

"设备描述符正确" 意味着：当主机发起 `GET_DESCRIPTOR(Device)` 请求时，设备必须返回一个字段值完全合法的 18 字节设备描述符。这是 USB 枚举流程中主机获取的第一条描述符，也是主机识别设备身份（VID/PID/USB 版本）的唯一途径。

```
主机发送 GET_DESCRIPTOR(Device, wLength=8)
    → 设备返回前 8 字节 (bLength ~ bMaxPacketSize0)
    → 主机解析: bMaxPacketSize0=64 → 后续用 64 字节读

主机发送 GET_DESCRIPTOR(Device, wLength=18)
    → 设备返回完整 18 字节
    → 主机解析: VID / PID / bcdUSB / iManufacturer / iProduct / iSerialNumber
    → 主机记录设备身份
```

> **TR1-02 的边界**：只要求设备描述符（18 字节）的字段值正确且能被主机读取。配置描述符（TR1-03）、字符串描述符（TR1-04）不在本需求范围。但实践中三者同时被主机请求，代码层面已在 TR1-01 一并实现。

## 3. 设备描述符字段设计

### 3.1 字段定义

`src/usb_desc.c` 中的 `MASS_DeviceDescriptor[18]`：

| 偏移 | 字段 | 设计值 | 字节序 | 验证点 |
|---|---|---|---|---|
| 0 | bLength | 0x12 (18) | 单字节 | 等于描述符总长度 |
| 1 | bDescriptorType | 0x01 (DEVICE) | 单字节 | 固定为 1 |
| 2~3 | bcdUSB | 0x0200 | 小端 [低,高] | USB 2.00；字节 [0x00, 0x02] |
| 4 | bDeviceClass | 0x00 | 单字节 | 类在接口级定义 |
| 5 | bDeviceSubClass | 0x00 | 单字节 | — |
| 6 | bDeviceProtocol | 0x00 | 单字节 | — |
| 7 | bMaxPacketSize0 | 0x40 (64) | 单字节 | EP0 最大包大小 64 字节 |
| 8~9 | idVendor | 0x0483 | 小端 [低,高] | STMicroelectronics；字节 [0x83, 0x04] |
| 10~11 | idProduct | 0x5720 | 小端 [低,高] | 字节 [0x20, 0x57] |
| 12~13 | bcdDevice | 0x0200 | 小端 [低,高] | 设备版本 2.00；字节 [0x00, 0x02] |
| 14 | iManufacturer | 1 | 单字节 | 指向字符串索引 1 |
| 15 | iProduct | 2 | 单字节 | 指向字符串索引 2 |
| 16 | iSerialNumber | 3 | 单字节 | 指向字符串索引 3 |
| 17 | bNumConfigurations | 1 | 单字节 | 仅 1 个配置 |

### 3.2 字节序说明

USB 描述符中的所有多字节字段（bcdUSB / idVendor / idProduct / bcdDevice）均采用 **小端序**（Little-Endian）：

```
bcdUSB = 0x0200 → 字节序列 [0x00, 0x02]   ← 偏移2=0x00, 偏移3=0x02
idVendor = 0x0483 → 字节序列 [0x83, 0x04]  ← 偏移8=0x83, 偏移9=0x04
idProduct = 0x5720 → 字节序列 [0x20, 0x57] ← 偏移10=0x20, 偏移11=0x57
```

> **常见错误**：将 idVendor 写为 `[0x04, 0x83]`（大端），会导致 USBTreeView 显示 VID=0x8304。代码中已正确使用小端序。

### 3.3 代码实现

```c
/* src/usb_desc.c */
const uint8_t MASS_DeviceDescriptor[MASS_SIZ_DEVICE_DESC] = {
    0x12,   /* bLength           = 18                            */
    0x01,   /* bDescriptorType   = DEVICE                        */
    0x00,   /* bcdUSB low  — 0x0200 = USB 2.00                    */
    0x02,   /* bcdUSB high                                       */
    0x00,   /* bDeviceClass    = 0 (接口级别定义)                 */
    0x00,   /* bDeviceSubClass                                    */
    0x00,   /* bDeviceProtocol                                    */
    0x40,   /* bMaxPacketSize0 = 64                              */
    0x83,   /* idVendor low   — 0x0483 (STMicroelectronics)      */
    0x04,   /* idVendor high                                     */
    0x20,   /* idProduct low  — 0x5720                          */
    0x57,   /* idProduct high                                    */
    0x00,   /* bcdDevice low  — 0x0200 = 2.00                    */
    0x02,   /* bcdDevice high                                    */
    1,      /* iManufacturer   — 字符串索引 1                     */
    2,      /* iProduct        — 字符串索引 2                     */
    3,      /* iSerialNumber   — 字符串索引 3                     */
    0x01    /* bNumConfigurations = 1                            */
};
```

```c
/* inc/usb_desc.h */
#define MASS_SIZ_DEVICE_DESC  18
extern const uint8_t MASS_DeviceDescriptor[MASS_SIZ_DEVICE_DESC];
```

## 4. GET_DESCRIPTOR(Device) 处理链路

### 4.1 完整调用链

```
主机发送 SETUP 包 (bmRequestType=0x80, bRequest=GET_DESCRIPTOR(6), wValue=0x0100, wLength=N)
    │
    ▼
USB 外设硬件 → CTR 中断 → USB_Istr() → CTR_LP()
    │
    ▼
usb_core.c: Setup0()  →  Data_Setup0()
    │
    ├── Request_No = pInformation->USBbRequest = 6 (GET_DESCRIPTOR)
    ├── Type_Recipient = STANDARD_REQUEST | DEVICE_RECIPIENT
    ├── wValue1 = pInformation->USBwValue1 = 0x01 (DEVICE_DESCRIPTOR)
    │
    └── CopyRoutine = pProperty->GetDeviceDescriptor
            │
            ▼
        usb_prop.c: MASS_GetDeviceDescriptor(Length)
            │
            └── return Standard_GetDescriptorData(Length, &Device_Descriptor)
                    │
                    ▼
                usb_core.c: Standard_GetDescriptorData()
                    │
                    ├── Length == 0:  返回 0, 设置 Usb_wLength = 18 - wOffset
                    │                 (告知核心库剩余数据总长)
                    └── Length != 0:  返回 pDesc->Descriptor + wOffset
                                      (返回当前分片数据指针)
```

### 4.2 分片返回机制

主机可能分两次请求设备描述符：

```
第 1 次请求: wLength = 8  (主机先读 8 字节探明 bMaxPacketSize0)
    → wOffset = 0,  返回 &MASS_DeviceDescriptor[0],  传输 8 字节
    → Usb_wLength = 18 - 0 = 18 (剩余 18 字节待传)

第 2 次请求: wLength = 64 (主机用完整包长读取)
    → wOffset = 8,  返回 &MASS_DeviceDescriptor[8],  传输 10 字节
    → 剩余 0 字节, 传输结束
```

> 核心库 `DataStageIn()` 负责将 `Standard_GetDescriptorData` 返回的指针数据拷贝到 PMA 的 EP0_TXADDR 缓冲区，并设置 `SetEPTxCount(ENDP0, len)` + `SetEPTxStatus(ENDP0, EP_TX_VALID)` 触发 IN 传输。最后一包（不足 MaxPacketSize 或恰好为 0）时自动发送 ZLP（Zero-Length Packet）。

### 4.3 ONE_DESCRIPTOR 包装

`usb_prop.c` 中将裸数组指针包装为 `ONE_DESCRIPTOR` 结构：

```c
static ONE_DESCRIPTOR Device_Descriptor = {
    (uint8_t *)MASS_DeviceDescriptor,   /* Descriptor     — 数据指针 */
    MASS_SIZ_DEVICE_DESC                /* Descriptor_Size = 18      */
};
```

`Standard_GetDescriptorData` 通过 `Descriptor_Size` 判断剩余长度，通过 `Descriptor + wOffset` 返回分片指针。

## 5. 数据流：GET_DESCRIPTOR(Device) 全过程

```
时间线      PC 侧                                  STM32 侧
──────────────────────────────────────────────────────────────────
T1          主机发送 SETUP 令牌
            bmRequestType=0x80 (IN, Standard, Device)
            bRequest=0x06 (GET_DESCRIPTOR)
            wValue=0x0100 (Device Descriptor)
            wLength=0x0008                        EP0 收到 SETUP 包
                                                   → CTR 中断 → CTR_LP()
                                                   → Setup0() → Data_Setup0()
                                                   → CopyRoutine = MASS_GetDeviceDescriptor
                                                   → Standard_GetDescriptorData(0)
                                                     设置 Usb_wLength=18
                                                   → DataStageIn()
                                                     拷贝 8 字节到 PMA
                                                     SetEPTxCount(EP0, 8)
                                                     SetEPTxStatus(EP0, TX_VALID)
T2          主机发送 IN 令牌                       EP0 IN → 返回 8 字节
            收到 8 字节
            解析: bMaxPacketSize0=64              → DataStageIn() 检测剩余 10 字节
            bLength=18, bDescriptorType=0x01        设置下一包: SetEPRxValid(EP0)
T3          主机发送 ACK + OUT (Status)
            ─────────────────────────────────────→ EP0 OUT → 状态阶段完成

T4          主机再次发送 SETUP
            wLength=0x0040 (64)                    EP0 收到 SETUP
            (用完整包长读取剩余)                    → Data_Setup0() → 同上
                                                   → Standard_GetDescriptorData(0)
                                                     Usb_wLength=18
T5          主机发送 IN                            EP0 IN → 返回 18 字节
            收到 18 字节                           (一次传完, 因 18 < 64)
            解析:
              VID=0x0483, PID=0x5720             → 传输完成, 发 ZLP? 否 (18<64)
              bcdUSB=0x0200 (USB 2.0)              状态阶段自动处理
              bMaxPacketSize0=64
              iManufacturer=1, iProduct=2
              iSerialNumber=3
T6          主机记录设备身份                         ✅ 描述符读取完成
```

## 7. 常见问题排查

| 现象 | 可能原因 | 排查方向 |
|---|---|---|
| USBTreeView 显示 VID=0x8304 | idVendor 字节序写反（大端） | 检查 `usb_desc.c` 偏移 8~9，应为 `[0x83, 0x04]` 而非 `[0x04, 0x83]` |
| USBTreeView 显示 PID=0x2057 | idProduct 字节序写反 | 检查偏移 10~11，应为 `[0x20, 0x57]` |
| bcdUSB 显示 1.10 | bcdUSB 值错误为 0x0110 | 检查偏移 2~3，应为 `[0x00, 0x02]` (0x0200) |
| bMaxPacketSize0 显示 8 或 16 | 偏移 7 值错误 | 应为 `0x40` (64)；全速设备 EP0 必须 8/16/32/64 之一 |
| 设备描述符全为 0x00 | `MASS_GetDeviceDescriptor` 未正确返回指针 | 检查 `usb_prop.c` 中 `Device_Descriptor.Descriptor` 是否指向 `MASS_DeviceDescriptor` |
| 只返回前 8 字节 | `MASS_SIZ_DEVICE_DESC` 不等于 18 | 检查 `usb_desc.h` 中宏定义 |
| USBTreeView 显示 "Device Descriptor Failed" | EP0 无法响应 GET_DESCRIPTOR | ① 检查 `MASS_Reset` 中 EP0 缓冲区地址 ② 检查 `fSuspendEnabled` 是否为 FALSE（TR1-01 修复） |
| 主机收到 18 字节但内容错乱 | PMA 缓冲区地址重叠 | 检查 `usb_conf.h` 中 ENDP0_TXADDR 是否为字偏移（0x40），不与 BTABLE/EP0_RXADDR 重叠 |
